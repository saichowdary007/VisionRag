# RAG Vision — Minimal LLM Context

## Goal
Build a local-first multimodal RAG app:
- Ingest PDFs → render pages → ColPali multi-vector embeddings → Milvus
- Ask questions → retrieve + MaxSim rerank → Qwen2.5-VL answers (via Ollama)
- Pretty single-page frontend: upload + chat + source thumbnails
- Apple Silicon (MPS) + Docker prod

## Tech
- Python: FastAPI, pdf2image/Pillow, pymilvus, colpali-engine, openai client
- Retriever: vidore/colpali-v1.3 (128d, 1024 patches/page)
- QA: qwen2.5-vl:7b (Ollama)
- Vector DB: Milvus (local/compose)
- Frontend: static index.html (vanilla JS)

## Endpoints
- GET  `/`                 → serve index.html
- POST `/upload`           → {file: PDF} → saves, splits to PNGs, embeds, inserts vectors
- POST `/ask`              → {query} → retrieve+rerank → Qwen2.5-VL → {answer,sources[]}
- GET  `/pages/<file>`     → static page thumbnails
- GET  `/health`           → status ok

## Env (read by api_service.py)
- MILVUS_URI=tcp://milvus:19530  (compose) | milvus.db (local lite)
- COLLECTION_NAME=rag_vision_collection
- QA_API_BASE=http://host.docker.internal:11434/v1
- QA_API_KEY=ollama
- QA_MODEL_ID=qwen2.5-vl:7b
- RETRIEVER_MODEL_ID=vidore/colpali-v1.3
- TOP_K_CANDIDATES=50
- TOP_K_FINAL=3
- IMAGE_DPI=200

    volumes:
      - ../documents:/app/documents
      - ../pages:/app/pages
      - ../index.html:/app/index.html
    extra_hosts: ["host.docker.internal:host-gateway"]
    depends_on: [milvus]

## Frontend behavior
- Drag/drop PDFs → POST /upload (FormData)
- Chat sends {query} to POST /ask
- Renders answer + thumbnails from `sources[].source_url` (served from /pages/*)

## Retriever flow (server)
- embed_query(text) → (1,Q,128)
- probe = mean(q) → vector search → candidate pages
- rerank via MaxSim (query tokens × 1024 patch vectors/page)
- pick top K pages → send as `image_path` to Qwen2.5-VL

## Run (local)
- Ollama: `ollama pull qwen2.5-vl:7b && ollama serve`
- Compose: `cd deployment && docker compose up -d --build`
- Open: http://localhost:8000

## Coding rules for agent
- Do NOT change API shapes without updating frontend fetch calls
- Keep `/ask` response: {"answer": str, "sources":[{page,score,source_url}]}
- When patching Docker/compose, preserve `host.docker.internal` workflow
- Prefer MPS if available; fallback CUDA → CPU
